# Paths that exist in the source repos (after the filter-repo rewrite into
# packages/<name>/) but were deliberately removed in this monorepo, because
# root-level files replace them.
#
# scripts/import-history.sh reads this file on every merge. For these paths only it:
#   - resolves a modify/delete conflict (the source changed a file we deleted)
#     by keeping the deletion;
#   - removes any file the source newly added under them (for example a new
#     workflow under .github/), so the merge never brings them back.
# Any other conflict aborts the merge.
#
# One path per line, relative to the repo root. A trailing / means the whole
# directory. Blank lines and lines starting with # are ignored. When you delete
# another imported file or directory from a package, add it here in the same PR.
